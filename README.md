#  Instagram Login Page Clone

> Projeto desenvolvido como desafio prático para recriação da interface de login do Instagram utilizando **CSS Flexbox** e conceitos de **Responsividade**.

---

##  Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout dinâmico com Flexbox e regras de media queries.

---

##  Funcionalidades e Aprendizados

* **Layout Flexbox:** Alinhamento centralizado do container principal e organização vertical dos cards de login.
* **Design Responsivo:** Ocultação automática do mock de celular em dispositivos móveis para melhorar a experiência do usuário.
* **Componentização de CSS:** Organização de estilos limpos para botões, inputs e links.
